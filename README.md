# Dubbing Room — 여럿이 나눠서 더빙하기

10명이 각자 집에서 접속해 **자기 캐릭터 대사만** 연습하고 녹음하면,
마지막에 **영상 한 파일**로 합쳐지는 수업용 웹사이트입니다.

```
더빙룸/
├─ index.html        ← 사이트 본체
├─ config.js         ← ⚠ Supabase 주소 두 줄만 채우면 됩니다
├─ segments.js       ← 배역·대사·타임코드 (대본이 바뀌면 여기만 고칩니다)
├─ schema.sql        ← Supabase 에 한 번 붙여넣고 Run
├─ serve.py         ← 로컬에서 열어볼 때 쓰는 서버
├─ build_final.py    ← 최종 영상 한 파일 만들기 (타이틀·크레딧 포함)
├─ make_credits.py   ← 오프닝 타이틀 / 엔딩 크레딧 그리기
└─ video/
   ├─ clip88.mp4     ← 더빙할 영상 (0:00–1:25.6, 720p, 앞뒤 페이드)
   ├─ clip_bgm.m4a   ← 목소리를 뺀 배경음악·효과음
   └─ clip_vocals.m4a← (참고용) 뺀 목소리만
```

---

## 지금 바로 열어보기

```bash
python3 ~/더빙룸/serve.py
```

브라우저에서 `http://localhost:4321/` 로 들어가세요.

> **`python3 -m http.server` 를 쓰면 안 됩니다.** 그건 Range 요청을 무시해서
> 영상을 중간으로 건너뛸 수 없습니다(구간 이동이 안 되니 더빙이 아예 안 됩니다).
> `serve.py` 는 그걸 처리하는 서버입니다. GitHub Pages 에 올리면 신경 쓸 필요 없습니다.

**파일을 더블클릭해서 열면 안 됩니다** — 반드시 위 주소로 열어야 마이크가 열립니다.

Supabase 를 아직 연결 안 했어도 연습·녹음·듣기는 전부 됩니다. (올리기만 안 됩니다)

## 1. 화면 구성

### 참가자
1. **이름 고르기** — 팀별로 10명이 보입니다. 자기 이름을 누르면 **내 대사만** 모여서 뜨고,
   타임라인에 **내 구간이 색으로 표시**됩니다.
2. **🎧 연습 모드**
   - 발음기호(IPA)·한글 번역이 같이 보입니다 (체크박스로 끄고 켜기)
   - **0.5× ~ 1.0×** 느린 속도로 들을 수 있습니다 (음높이는 그대로)
   - `🔁 반복` 정한 횟수만큼 돌려주기 · `🗣 섀도잉` 한 번 들려주고 그만큼 비워주기
3. **🎙 더빙 모드**
   - `● 녹음` 을 누르면 1.5초 세어준 뒤 그 대사 자리에서 영상이 돌아갑니다
   - 녹음은 **바로 자동 저장·업로드**됩니다
   - **여러 번 녹음해 두고 고를 수 있습니다.** 녹음할 때마다 `1번 · 2번 · 3번…` 으로 쌓이고,
     각각 `▶` 로 들어본 뒤 `★` 로 제출할 것을 고르면 됩니다. `✕` 는 그 테이크만 지웁니다.
   - `🎬 영상에 맞춰` — 영상과 겹쳐 틀어 입모양·타이밍이 맞는지 확인
   - `🗑 전부 지우기` — 그 대사의 녹음을 모두 지우고 처음부터
   - 새로고침하거나 컴퓨터를 꺼도 녹음은 남아 있습니다

   **파형 비교** — 녹음하면 대사 아래에 파형이 그려집니다.
   **위가 원본, 아래가 내 녹음**이고 점선이 대사 끝입니다.
   귀로 듣지 않아도 빠른지 늦은지 눈으로 보이고, 아래에 한 줄로 설명도 붙습니다
   (예: `원본보다 0.4초 늦게 시작했습니다. 끝이 0.3초 넘칩니다`).

   **타이밍 자동 점검** — 녹음이 끝나면 바로 짚어줍니다.
   `⏱ 타이밍 좋습니다` / `말 시작이 0.6초 늦었습니다` / `대사가 구간보다 0.8초 깁니다`
   그리고 다음 녹음할 대사로 자동으로 넘어갑니다.

   **앞 대사 듣고 시작** (기본 켜짐)
   - 녹음 직전 3초 동안 **앞 대사를 들려줍니다.** 앞사람 톤을 이어받으라는 장치입니다.
   - 팀원이 **이미 녹음해 뒀으면 그 목소리**로, **아직 안 했으면 원음**으로 들려주고,
     화면에 `앞 대사: 엄마(Coach_Jun 님) · 까칠이(아직 녹음 전 — 원음)` 처럼 무엇이 들리는지 적어줍니다.
   - **앞 대사는 녹음에 들어가지 않습니다.** 녹음은 내 대사가 시작되는 바로 그 지점부터
     시작되고, 그 순간 앞 대사 재생은 꺼집니다.

   **영상 소리** 선택
   - `배경음악만` (기본) — 원본 대사 없이 **분리해둔 배경음악 위에서** 연습·녹음합니다
   - `원본 그대로` — 원어민 대사를 들으며 맞춰보고 싶을 때

4. **다른 사람 녹음도 같이 들립니다**
   - 20초마다 자동으로 새 녹음을 받아옵니다. 누가 올리면 안내가 뜹니다.
   - `▶ 지금까지 더빙 들어보기` — 배경음악 위에 **내 녹음 + 다른 분들 녹음**을 전부 얹어
     우리 팀 구간을 통째로 들려줍니다. 아직 비어 있는 줄은 조용히 지나갑니다.
   - 타임라인에서 **다른 사람 대사를 눌러도** 그분 녹음을 영상과 함께 들을 수 있습니다.

단축키 — `1` 연습 모드 · `2` 더빙 모드 · `Esc` 정지

> (예: `.../?upload=1`) 대사마다 `📁 파일 올리기` 가 생겨서, 휴대폰 녹음기 앱으로 녹음한

- **`⤓ 본편 영상 받기 (MP4)`** — 10명 녹음을 배경음악 위에 얹은 영상입니다.
  브라우저에서 바로 받을 수 있어 **빠른 확인용**으로 좋습니다.
  단, **오프닝 타이틀과 엔딩 크레딧은 들어가지 않습니다** (아래 5번 참고)
- `⤓ 합본 음원만 (WAV)` — 편집 프로그램에서 직접 얹고 싶을 때
- `⤓ 개별 녹음 모아서 (ZIP)` — 10명의 녹음 파일 전부 + `대사목록.txt` 를 **한 파일로**
- `▶ 합본 들어보기` / `⏱ 타이밍 맞추기` (아래 3번)

### 🔎 타이밍 일괄 점검

제출된 녹음을 전부 받아 타이밍을 재서, **문제 있는 줄만 골라냅니다.**
31줄을 일일이 들어볼 필요가 없습니다.

```
점검 끝 — 다시 찍는 게 좋은 줄 2개: 7번 엄마(Coach Hazel) 시작 0.8초 늦음,
19번 라일리(Coach Rachel) 0.7초 넘침
살짝 아쉬운 줄 1개: 23번 그레이스(Coach Julia) 0.4초 넘침
```

표에도 `시작 0.8초 늦음` 같은 꼬리표가 붙습니다
(빨강 = 다시 찍는 게 좋음 / 노랑 = 살짝 아쉬움 / 초록 = 좋음).
살짝 어긋난 정도면 아래 **싱크 미세조정**으로 밀고 당겨 해결할 수도 있습니다.

### 싱크 미세조정

제출된 대사마다 표 오른쪽에 조정 칸이 생깁니다.

| 버튼 | 하는 일 |
|---|---|
| `▶` | 그 대사만 영상과 같이 들어보기 (조정값 반영된 소리로) |
| `◀ 50` | 50ms 당기기 (더 빨리 나오게) |
| `50 ▶` | 50ms 밀기 (더 늦게 나오게) |
| `↺` | 0 으로 되돌리기 |

**원본 녹음은 건드리지 않습니다.** "몇 ms 옮길지" 만 따로 저장해서, 합본을 만들 때 그만큼 옮겨 얹습니다.
그래서 몇 번을 조정해도 음질이 나빠지지 않고, 언제든 0 으로 되돌릴 수 있습니다.
조정값은 `합본 들어보기`·`본편 영상 받기`·`build_final.py` 모두에 똑같이 반영됩니다. (최대 ±3초)

> MP4 만들기는 브라우저 안에서 돕니다. **처음 한 번만** 합치기 도구(약 32MB)를 내려받고,
> 그 뒤로는 1~2분이면 끝납니다. 인터넷이 막혀 도구를 못 받으면 합본 음원(WAV)을 대신 내려받고
> 안내 문구가 뜹니다.

암호는 `config.js` 의 `ADMIN_KEY` 에서 바꾸세요. **학생에게는 `?admin` 없는 주소만** 알려주세요.

## 2. Supabase 연결 (한 번만, 5분)

1. [supabase.com](https://supabase.com) 가입 → `New project` (무료 플랜으로 충분합니다)
2. 좌측 **SQL Editor** → `schema.sql` 내용을 통째로 붙여넣고 **Run**
3. 좌측 **Settings → API** 에서 두 값을 복사해 `config.js` 에 붙여넣기

```js
SUPABASE_URL: "https://xxxxxxxx.supabase.co",
SUPABASE_ANON_KEY: "eyJhbGciOi...",
```

> `anon key` 는 공개되어도 되는 키입니다. 대신 **링크를 아는 사람은 누구나 녹음을 올리고 지울 수 있습니다** —
> 수업용이라 일부러 이렇게 열어둔 것이고(다시 찍기 기능 때문), 끝나면 `schema.sql` 맨 아래 4번을 실행해 잠그면 됩니다.

## 3. 타이밍 맞추기 (한 번만, 2분) — **꼭 해주세요**

지금 `segments.js` 의 대사 시간은 대본의 블록 타임코드에서 **추정한 값**이라 살짝 어긋납니다.

1. 관리자 화면 → `⏱ 타이밍 맞추기`
2. `▶ 처음부터` 를 누르고 영상을 보면서, **대사가 시작될 때마다 스페이스바**
3. 31번까지 다 찍었으면 `⤓ 새 lines 내려받기`
4. 받은 `lines.txt` 내용으로 `segments.js` 의 `lines: [ ... ]` 부분을 통째로 교체

이걸 해두면 녹음 타이밍도, 최종 합본도 정확히 맞습니다.

## 4. 인터넷에 올리기 (GitHub Pages)

맥에 GitHub Desktop 이 설치돼 있습니다.

1. GitHub Desktop → `File → Add Local Repository` → `~/더빙` 선택 → `Create a repository`
2. `Publish repository` — 학생이 봐야 하므로 **Keep this code private 체크 해제**
3. github.com 의 저장소 → `Settings → Pages` → Source 를 `main` / `/ (root)`
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/` 로 접속

10명에게는 이 주소를 알려주면 됩니다. 영상이 15MB 라 첫 접속만 조금 걸립니다.

## 4-2. 크레딧 소감 (목소리)

더빙 모드 화면 아래에 **🎤 크레딧 소감** 칸이 있습니다.
각 코치님이 **10~15초 정도로 짧게** 한마디 녹음하면, 영상 맨 끝 크레딧이 올라갈 때
**본인 이름이 화면 가운데 올 때 그 목소리가 나옵니다.** (최대 25초)

- 녹음 / 들어보기 / 지우고 다시 녹음 모두 됩니다
- 소감을 안 남겨도 괜찮습니다 — 그 사람은 이름만 잠깐 지나갑니다
- 크레딧 길이와 스크롤 속도는 **소감 길이에 맞춰 자동으로 계산**됩니다
  (소감이 길면 천천히 흘러서 이름이 화면에 머뭅니다)

## 4-3. 오프닝 타이틀 · 엔딩 크레딧

최종 영상을 만들면 앞뒤에 자동으로 붙습니다. 따로 할 일은 없습니다.

```
[오프닝 4초]  SORITUNE DUBBING / Dream Productions / 화이트 팀 · 블랙 팀
[본편 1:25.6]
[엔딩 크레딧]  출연 — 배역 ····· 코치 이름  (소감 목소리와 함께 위로 스크롤)
              고생하셨습니다 / 소리튠 더빙 프로젝트
```

배역표는 `segments.js` 의 `cast` 에서 자동으로 읽어오므로, 배역이 바뀌면 거기만 고치면 됩니다.
크레딧만 따로 미리 보려면:

```bash
~/.dubtools/bin/python ~/더빙룸/make_credits.py --fetch
```

`_credits/title.png` 와 `_credits/credits.png` 가 생깁니다.
앞뒤 없이 본편만 뽑고 싶으면 `build_final.py --no-titles` 를 쓰세요.

## 5. 최종 영상 한 파일로 만들기

**타이틀·크레딧까지 들어간 완성본은 터미널에서만 나옵니다.**
관리자 화면의 `⤓ 본편 영상 받기` 는 더빙만 입힌 영상이라 확인용이고,
오프닝과 엔딩 크레딧(소감 목소리 포함)을 붙이려면 아래를 돌리세요:

```bash
~/.dubtools/bin/python ~/더빙룸/build_final.py
```

**두 개가 같이 만들어집니다:**

| 파일 | 내용 |
|---|---|
| `본편만.mp4` | 배경음악 위에 10명 목소리만 얹은 영상 |
| `완성본.mp4` | 오프닝 타이틀 + 본편 + 엔딩 크레딧(소감 목소리 포함) |

본편은 중간 산물이라 따로 만드는 시간이 거의 들지 않습니다. 둘 다 받아두고 골라 쓰시면 됩니다.

| 옵션 | 설명 |
|---|---|
| `--only white` | 화이트 팀 구간만 |
| `--only black` | 블랙 팀 구간만 |
| `--orig` | 배경음악 대신 원본 소리 위에 얹기 (확인용) |
| `--no-titles` | 완성본을 만들지 않고 `본편만.mp4` 만 |

아직 안 올라온 대사가 있으면 그 자리는 배경음악만 들어가고, 몇 줄이 비었는지 알려줍니다.
나중에 다 모이면 다시 돌리면 됩니다.

## 배경음악은 어떻게 뺐나

`demucs`(AI 음원 분리)로 **목소리 / 배경음악**을 갈라 목소리 쪽을 버렸습니다.
0–22초 구간 기준으로 원본보다 **12.7dB 조용해졌습니다** — 대사가 대부분 사라졌다는 뜻입니다.

완벽하진 않습니다. 대사와 음악이 크게 겹치던 자리는 음악이 살짝 먹먹하고, 효과음은 대체로 남아 있습니다
(더빙용으로는 오히려 좋습니다). 원본 그대로 쓰고 싶으면 `segments.js` 의 `videoBgm` 을 `null` 로 바꾸세요.

다른 영상에 다시 쓰려면:

```bash
FF=~/.dubtools/lib/python3.9/site-packages/imageio_ffmpeg/binaries/ffmpeg-macos-x86_64-v7.1
"$FF" -i 새영상.mp4 -vn -ac 2 -ar 44100 -c:a pcm_s16le 새영상.wav
~/.dubtools/bin/python -m demucs --two-stems=vocals -n htdemucs -o 결과 새영상.wav
"$FF" -i 결과/htdemucs/새영상/no_vocals.wav -c:a aac -b:a 160k clip_bgm.m4a
```
